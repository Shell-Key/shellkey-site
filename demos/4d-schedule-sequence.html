How to use TXI 4D

1 Project — name it, then Save project whenever you like. The file holds everything, including the pictures and built layers, so it can be moved to another PC.

2 Schedule — import a P6 XER, a Primavera XML or a Microsoft Project XML (Project: File → Save As → XML). Choose which activity code (or WBS level) is the work area and which is the discipline. The rules box maps code values and activity names to the six groups: Foundations, Steel, Equipment, Piping, E&I, Test & turnover. Overrides per activity are kept.

3 Images & areas — add pictures (model screenshots, plot plan, photos). For each area click points around it, double-click to close. Outlines can be copied between pictures taken from the same camera.

4 Colours → disciplines — click Find colours, assign each swatch, brush any corrections, then Build. The picture is split into per-area, per-discipline layers; every layer carries an installation order (racks west→east, steel ground-up, pads and equipment largest first). The ground underneath is rebuilt from the surrounding terrain.

5 4D playback — Space plays, arrow keys step a day (Shift = a month), Esc clears isolation. Save any frame as PNG, or export monthly frames as a ZIP to make a video in any editor.

Sharing — give people this HTML file and your project file; nothing else is needed and no internet is used.
